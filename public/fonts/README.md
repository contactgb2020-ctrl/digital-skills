# Glacial Indifference — fichiers de police à ajouter ici

Cette police n'est pas disponible sur Google Fonts (licence commerciale,
gratuite pour usage personnel). Ajoute ici tes fichiers avec exactement
ces noms pour qu'ils soient utilisés automatiquement par le site :

- `GlacialIndifference-Regular.woff2` (poids 400 — texte courant)
- `GlacialIndifference-Medium.woff2`  (poids 500 — titres et accents)

Si tu n'as que des fichiers .otf/.ttf, convertis-les en .woff2 (plus léger
pour le web) via https://cloudconvert.com/ttf-to-woff2 par exemple.

Tant que ces fichiers ne sont pas présents, le site utilise une police de
secours propre (Segoe UI / système) pour ne jamais rien casser.
